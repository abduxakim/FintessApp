# Подход — личный дневник тренировок

Приложение-артефакт для Claude: программы тренировок под цель, ведение подходов с таймером и подсказкой прошлого результата, история и рекорды. Данные хранятся на устройстве и синхронизируются в личное облачное хранилище артефакта.

- Код: `apps/web`
- План и этапы: [docs/PLAN.md](docs/PLAN.md)
- Модель данных: [docs/data-model.md](docs/data-model.md)

```bash
cd apps/web
npm install
npm test          # unit-тесты
npm run build     # dist/fitness.html — файл для публикации артефактом
npm run e2e       # сквозная проверка в Chromium
```

Приложение не заменяет врача: при боли, онемении или ухудшении обращайся к специалисту.
