# План разработки

## Решения
- **Платформа:** артефакт Claude (одна HTML-страница). Работает с телефона (Android) через приложение Claude или браузер, без хостинга и платных сервисов.
- **Стек:** React 18 (UMD с cdnjs) + TypeScript, сборка Vite в один файл. Шрифты встроены.
- **Данные:** local-first. Запись → IndexedDB на устройстве → очередь outbox → личное облачное хранилище артефакта (`db`, путь `data/users/<id>/…`, приватно). На новом устройстве всё восстанавливается из облака. Экспорт/импорт JSON-файлом.
- **AI (этап 4):** возможность артефакта `sample` с изображениями — без API-ключа и прокси. Наружу уходят только фото/текст еды.
- **Программы** идут «по очереди» (A → B → C), а не по дням недели — под нерегулярный график.

| 1 | Профиль и онбординг, библиотека упражнений (~90), 7 шаблонов + 4 блока, подбор программы, активная тренировка (подходы, таймер, «прошлый раз», замена, односторонние Л/П), история, рекорды, синхронизация, бэкап | ✅ |

| 3 | Вода, сон, восстановление и готовность | |
| 4 | Питание по фото и тексту через Claude | |
| 5 | Напоминания, недельная сводка, экспорт CSV | |

## Проверки
- `npm test` — unit-тесты доменной логики и целостности каталога.
- `npm run build && npm run e2e` — сквозной сценарий в Chromium, включая синхронизацию с фейковым облаком и восстановление на чистом устройстве.
